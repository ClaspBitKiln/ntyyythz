# Проверка дизайна и реализации

Дата: 13 августа 2026 года.

## Утверждённые ограничения

- Первый экран использует точную копию `САЙТ первая страница(2).png`; контрольная SHA-256 совпадает с исходником.
- Композиция изображения не перерисована. На desktop используется центр исходного кадра; на mobile сохраняется правая промышленная сцена с грузовым автомобилем.
- Эмблема используется как отдельный неизменённый растровый файл.
- Новые варианты дизайна не создавались.

## Функциональная проверка

- `npm run generate:types` — успешно.
- `npm run lint` — без ошибок; предупреждения только в стандартных тестовых файлах шаблона.
- `npm run build` — успешно; TypeScript и production build проходят.
- Главная страница, Payload Admin, REST/GraphQL API и `/api/request` присутствуют в production routing table.
- Форма ограничивает общий размер файлов 25 МБ и разрешает Excel, PDF, Word, изображения, DWG и DXF.
- Заявка сохраняется в Payload, затем при наличии настроек отправляется по SMTP и/или в CRM webhook.

## Ограничение среды проверки

Локальный сервер отвечает корректным HTML, но облачный браузер в текущей среде не смог подключиться к локальному порту. Поэтому финальная интерактивная визуальная проверка в облачном браузере остаётся обязательной перед production-публикацией.
