# Сайт «Мэджик Металл»

Корпоративный B2B-сайт и система обработки заявок на Next.js 16, Payload CMS 3 и PostgreSQL.

## Что реализовано

- утверждённый первый экран на изображении `hero-approved.webp` без изменения композиции;
- продуктовый приоритет: электросварные трубы, бесшовные трубы, СДТ, трубы и фасонные изделия в изоляции;
- расширенный трубный каталог по презентации «Мэджик Металл» и техническим данным Металлайн, МетПромУрал, УМПЦ и ПМСМК;
- статически генерируемый SEO-справочник материалов с отдельными страницами марок, ГОСТами, свойствами, применением и перелинковкой на товары;
- статический справочник ГОСТ с официальными источниками и двусторонней связью «стандарт ↔ материал ↔ товар ↔ заявка»;
- единый браузерный поиск по продукции, маркам, ГОСТам и применению без серверной задержки;
- калькулятор теоретической массы трубы, листа, круга и квадрата;
- отдельная посадочная страница поставок в Узбекистан как одного из приоритетных рынков РФ + СНГ;
- Payload Admin (`/admin`) для каталога, заявок, файлов и настроек сайта;
- форма заявки с Excel, PDF, Word, изображениями, DWG и DXF;
- сохранение заявок и файлов, SMTP-уведомление на `m1@magicmet.ru`, опциональный CRM webhook;
- UTM/referrer/source tracking, базовая защита от спама, адаптивная верстка и SEO-метаданные.
- готовые подключения Яндекс Метрики и GA4 через переменные среды, цель `request_sent` и событие `generate_lead`;
- статическая генерация товарных и справочных страниц: рост справочника не добавляет тяжёлую клиентскую логику и не требует запроса к базе при каждом просмотре.

## SEO-архитектура

- `/produkciya/[slug]` — товарные категории;
- `/spravochnik-materialov` и `/spravochnik-materialov/[slug]` — справочник материалов;
- `/spravochnik-gost` и `/spravochnik-gost/[slug]` — справочник нормативных документов;
- `/poisk` — единый технический поиск;
- `/kalkulyator-metalla` — калькулятор массы;
- `/postavki/uzbekistan` — поставки на приоритетный рынок Узбекистана;
- `sitemap.xml` содержит главную, товарные, справочные и региональные страницы.

Региональные страницы создаются только при наличии уникальной информации о поставке. Геоперсонализация может менять логистическую подсказку, контакт и CTA, но не подменяет индексируемый основной контент.

## Локальный запуск

1. Скопировать `.env.example` в `.env` и задать `PAYLOAD_SECRET`.
2. Запустить PostgreSQL: `docker compose up -d postgres`.
3. Установить зависимости: `npm install`.
4. Запустить: `npm run dev`.
5. Открыть `http://localhost:3000`; админ-панель — `http://localhost:3000/admin`.

После первого запуска создайте администратора и выполните `npm run seed`, чтобы добавить стартовый каталог.

## Переменные интеграций

- `SMTP_*` — отправка заявки с файлами на почту;
- `REQUEST_TO_EMAIL` — получатель, по умолчанию `m1@magicmet.ru`;
- `CRM_WEBHOOK_URL` — передача заявки в CRM;
- `NEXT_PUBLIC_YANDEX_METRIKA_ID` — счётчик Яндекс Метрики;
- `NEXT_PUBLIC_GA4_ID` — идентификатор Google Analytics 4;
- `NEXT_PUBLIC_SITE_URL` — канонический адрес сайта.
