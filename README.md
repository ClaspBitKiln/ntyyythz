# Мэджик Металл — сайт-воронка

SEO-ориентированный сайт ООО «Мэджик Металл» для продаж промышленным предприятиям России и СНГ.

## Первый этап

На первом этапе для России, Узбекистана, Казахстана, Кыргызстана и остальных стран используется **одна общая страница**, подготовленная по утверждённой презентации.

Без отдельных региональных дизайнов, отраслевых воронок и сложной персонализации.

Основной путь посетителя:

1. открыть общую страницу;
2. посмотреть основные группы продукции и условия доставки;
3. отправить короткую заявку;
4. получить уточнение, цену и срок от менеджера.

Региональные адреса временно перенаправляются на главную страницу. Отдельные версии можно вернуть позднее после накопления реальных заявок и поисковой статистики.

## Форма заявки

Форма содержит три пользовательских поля:

1. имя;
2. телефон или e-mail;
3. заявка / комментарий.

Источник перехода, UTM-метки и страница входа добавляются автоматически.

## Связка с SaaS

На текущем этапе сайт собирает заявки через обработчик формы. Подключение SaaS, лид-скоринга, геолокации и персонализации отложено до следующего этапа.

Интерфейс формы при будущем подключении SaaS менять не потребуется.

## Локальный запуск

Откройте `index.html` в браузере или запустите простой сервер:

```bash
python -m http.server 8080
```

## Перед публикацией

1. Подключить домен `www.magicmet.ru`.
2. Проверить отправку формы.
3. Проверить мобильное отображение на ширине 390 px.
4. Указать реальные идентификаторы систем аналитики после утверждения.
5. Добавить сайт в Яндекс Вебмастер и Google Search Console.
6. Подключить API SaaS отдельным этапом.
