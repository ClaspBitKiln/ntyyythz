# Мэджик Металл — сайт-воронка

SEO-ориентированный сайт ООО «Мэджик Металл» для прямых продаж промышленным предприятиям России и СНГ.

## Текущий приоритет

Первый рынок — Узбекистан. Раздел `/uz/` построен как отдельная воронка для конечных производственных покупателей, а не как общий прайс металлобазы.

Структура:

- `/uz/` — главная страница рынка Узбекистана;
- `/uz/catalog.html` — полный каталог;
- `/uz/otrasli.html` — выбор по отрасли;
- отраслевые страницы для машиностроения, энергетики, нефтегаза и химии, металлоконструкций, электротехники и цветных металлов;
- товарные страницы труб, листа и спецсталей, поковок, нержавеющей стали и промышленных комплектующих;
- `/uz/uz/` — узбекская языковая версия первого уровня.

## Форма заявки

Форма намеренно сокращена до трёх полей:

1. имя;
2. телефон или e-mail;
3. заявка / комментарий.

Страница, рынок, язык, UTM-метки, referrer, session ID и источник перехода добавляются автоматически.

По умолчанию форма работает через Netlify Forms. Для будущей связки с SaaS можно задать перед загрузкой `uz.js`:

```html
<script>window.MM_LEAD_API_URL = 'https://saas.example.com/api/public/leads';</script>
```

После этого заявка отправляется JSON-запросом в SaaS без изменения интерфейса сайта.

## Локальный запуск

Откройте `index.html` в браузере или запустите простой сервер:

```bash
python -m http.server 8080
```

## Перед публикацией

1. Подключить домен `www.magicmet.ru`.
2. Указать реальные ID Яндекс.Метрики и GA4.
3. Развернуть сайт на Netlify или другом хостинге с обработчиком форм.
4. Проверить все формы и мобильное отображение на ширине 390 px.
5. Добавить сайт в Яндекс Вебмастер и Google Search Console.
6. Подключить API SaaS после готовности публичного endpoint для лидов.
