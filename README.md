# Мэджик Металл — сайт-воронка

Новый быстрый SEO-ориентированный сайт ООО «Мэджик Металл» без Lovable.

Основа: статический HTML/CSS/JS с возможностью развернуть на Netlify, Vercel или любом хостинге. Форма подготовлена для Netlify Forms и отправляет заявки без отдельного сервера после подключения сайта к Netlify.

## Локальный запуск

Откройте `index.html` в браузере или запустите простой сервер:

```bash
python -m http.server 8080
```

## Перед публикацией

1. Подключить домен `www.magicmet.ru`.
2. Указать реальные ID Яндекс.Метрики и GA4 в `app.js`.
3. Развернуть на Netlify для работы формы и загрузки спецификаций.
4. Добавить сайт в Яндекс Вебмастер и Google Search Console.
