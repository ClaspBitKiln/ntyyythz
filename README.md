# Мэджик Металл — сайт-воронка

SEO-ориентированный сайт ООО «Мэджик Металл» для продаж промышленным предприятиям России и СНГ.

## Роль сайта

Сайт — публичный вход в единую SaaS-воронку продаж, а не отдельный лендинг. Он должен:

1. привлекать поисковый и рекламный трафик;
2. показывать основные группы продукции и условия поставки;
3. собирать короткие заявки и спецификации;
4. передавать в SaaS контакт, текст заявки, источник, UTM-метки, страницу входа и анонимную историю действий;
5. запускать рабочий процесс менеджера: `получил заявку → рассчитал прибыль → сформировал КП → поставил следующее касание`.

## Первый этап

На первом этапе для России, Узбекистана, Казахстана, Кыргызстана и остальных стран используется одна общая страница. Отдельные SEO-страницы каталога, марок, услуг, отраслей и стран добавляются на следующей итерации, но используют тот же формат лидов и событий.

Основной путь посетителя:

1. открыть сайт из поиска, рекламы или прямого перехода;
2. посмотреть группы продукции и условия доставки;
3. отправить заявку или нажать на телефон/e-mail;
4. получить уточнение, цену и срок от менеджера;
5. продолжить работу уже внутри SaaS и CRM-процесса.

## Форма заявки

Форма содержит три пользовательских поля:

1. имя;
2. телефон или e-mail;
3. заявка / комментарий.

Автоматически добавляются:

- `externalLeadId`;
- `sessionId`;
- источник сайта;
- UTM-метки;
- referrer;
- первая и текущая страницы;
- дата и время отправки;
- согласие на обработку персональных данных.

## Связка с SaaS

Настройки находятся в `site-config.js`.

- `saasLeadEndpoint` — публичный endpoint приёма заявок;
- `saasEventEndpoint` — endpoint событий воронки;
- `formFallbackEndpoint` — резервная отправка формы;
- `sourceSystem` — стабильный источник `magicmet-website`.

При настроенном SaaS endpoint заявка сначала передаётся туда. При ошибке или до запуска API используется резервный канал Netlify Forms, поэтому обращения не теряются.

Подробный контракт: [`docs/SAAS-INTEGRATION.md`](docs/SAAS-INTEGRATION.md).

## События воронки

Сайт уже формирует события:

- `page_view`;
- `product_group_view`;
- `form_start`;
- `phone_click`;
- `email_click`;
- `lead_submit`;
- `lead_success`;
- `lead_error`.

После подключения endpoint они передаются в SaaS и связываются с лидом по `sessionId`.

## Локальный запуск

Откройте `index.html` в браузере или запустите простой сервер:

```bash
python -m http.server 8080
```

## Перед публикацией

1. Подключить домен `www.magicmet.ru`.
2. Указать реальные SaaS endpoints в `site-config.js`.
3. Проверить создание лида и защиту от дублей по `X-Idempotency-Key`.
4. Проверить резервную отправку формы.
5. Проверить мобильное отображение на ширине 390 px.
6. Указать реальные идентификаторы систем аналитики после утверждения.
7. Добавить сайт в Яндекс Вебмастер и Google Search Console.
8. Настроить серверную антиспам-защиту и rate limit публичного API.
