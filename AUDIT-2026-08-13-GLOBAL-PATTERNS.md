## Открытые release gates

### High — антивирусная проверка вложений

- Риск: корректный по сигнатуре PDF/Office-файл всё равно может содержать вредоносную нагрузку для менеджера.
- Требование: до публичного запуска подключить ClamAV или сервис malware scanning; файлы до результата держать закрытыми. Сейчас чтение файлов заявки уже доступно только авторизованным сотрудникам.

### High — распределённая защита API

- Риск: in-memory rate limit не работает между несколькими экземплярами и не ограничивает chunked body на уровне reverse proxy.
- Требование: на production настроить WAF/reverse proxy с лимитом тела, rate limiting и корректной очисткой `X-Forwarded-For`; при масштабировании использовать Redis/Upstash или эквивалент.

### Medium — оставшиеся audit-зависимости

- Пять Moderate относятся к старому `esbuild` внутри `drizzle-kit`, который приходит через `@payloadcms/db-postgres`; автоматического исправления нет.
- Advisory относится к development server. Его нельзя публиковать наружу. Отслеживать обновление Payload и повторять audit при каждом релизе.

### Medium — аналитика и согласие

- Метрика и GA4 выключены, пока ID не заданы.
- До активации согласовать политику обработки данных и требуемый режим consent для выбранных рынков.

### Medium — реальное браузерное и полевое тестирование

- В текущем окружении production-сервер нельзя полноценно открыть через браузер из-за системного ограничения сетевых интерфейсов.
- На staging обязательны Playwright, Lighthouse, мобильный Android, Safari/Chrome/Edge, проверка LCP/INP/CLS и реальной выдачи Next Image.

## Производительность

- 58 маршрутов; товарные и справочные страницы генерируются статически.
- HTML: главная около 31 КБ, поиск около 32 КБ, крупнейший справочный hub около 44 КБ.
