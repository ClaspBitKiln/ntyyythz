# Персонализация сайта и связка с SaaS

## Текущий статус

На первом этапе персонализация и отдельные региональные версии **не используются**.

Для России, Узбекистана, Казахстана, Кыргызстана и остальных стран действует одна общая страница `https://www.magicmet.ru/`, созданная по утверждённой презентации.

## Что работает на первом этапе

- единая структура и дизайн для всех посетителей;
- общий перечень продукции;
- доставка по РФ и СНГ;
- одна короткая форма заявки;
- поля: имя, телефон или e-mail, заявка / комментарий;
- фиксация источника перехода и UTM-меток;
- передача заявки менеджеру.

Регион определяется только из текста заявки и источника рекламной кампании. Сайт не меняет содержимое по IP и не пытается определить организацию посетителя.

## Что отложено

До отдельного решения не разрабатываются:

- разные страницы для России и стран СНГ;
- автоматическое определение страны и города;
- поиск организации по геолокации;
- узбекская и другие языковые версии;
- персональные рекомендации;
- лид-скоринг;
- отдельные товарные воронки по странам;
- автоматическое создание карточки в SaaS.

## Будущая связка с SaaS

После запуска и накопления реальных заявок можно подключить единый API. Базовый набор данных:

- имя;
- телефон или e-mail;
- текст заявки;
- страница входа;
- источник и UTM-метки;
- дата и время отправки;
- анонимный идентификатор сессии.

Интерфейс формы при этом останется прежним.

## Правило следующего этапа

Усложнение сайта допускается только после появления подтверждённой необходимости по данным:

- реальные поисковые запросы;
- заявки с сайта;
- конверсия формы;
- география покупателей;
- повторяющиеся товарные группы;
- обратная связь менеджеров.

До этого момента поддерживается одна быстрая и понятная страница для всех рынков.
