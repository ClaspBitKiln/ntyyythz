# Контакты проекта Magic Metal

## Временный единый e-mail

До отдельного изменения использовать во всех публичных контактах, формах, уведомлениях и интеграциях:

```text
m1@magicmet.ru
```

Не использовать другие адреса как получателей заявок с сайта до отдельного изменения.

## Правило для интеграции с SaaS

Все уведомления о новых заявках, ошибках доставки заявки и резервных обращениях направлять на `m1@magicmet.ru`.

Рекомендуемая переменная окружения:

```env
LEAD_NOTIFICATION_EMAIL=m1@magicmet.ru
```
